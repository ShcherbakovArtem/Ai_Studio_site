# NEURA — AI Content Generation Studio

## Что это
Лендинг-сайт студии NEURA, которая предоставляет услуги по генерации AI-контента на заказ. Клиент отправляет бриф через форму — команда генерирует контент (видео, изображения, тексты, музыку, 3D, код) и возвращает готовый результат. Это НЕ платформа для самостоятельной генерации — это сервис "под ключ".

## Стек
- Чистый HTML/CSS/JS, без фреймворков и сборщиков
- Шрифты: Instrument Serif (заголовки), Space Grotesk (лейблы/индексы), Inter (body)
- Хостинг: Cloudflare Workers (wrangler deploy)
- Репозиторий: https://github.com/ShcherbakovArtem/Ai_Studio_site
- Продакшн URL: https://ai-studio-site.artshcherbakov99.workers.dev

## Структура файлов
```
index.html       — основной HTML
styles.css       — все стили
script.js        — анимации, i18n, тема, форма
public/          — копия файлов для деплоя (wrangler берёт из ./public)
wrangler.jsonc   — конфиг Cloudflare Workers
reference/       — 6 JPG-референсов дизайна (Studio Aton, Dazed, DigitalDynasty, и др.)
```

## Дизайн (согласованный)
- **Стиль**: editorial, вдохновлён референсами Studio Aton, Dazed, DigitalDynasty, Summertime, The Social Club
- **Акцентный цвет**: ядовитый лайм `#d4ff2b` (в светлой теме `#9fcc1a`)
- **Тёмная тема** по умолчанию (`--bg:#0a0a0a`), есть переключатель на светлую (`--bg:#f4f3f0`)
- **Курсор**: стандартный системный, pointer на интерактивных элементах
- **Grain overlay**: лёгкая зернистость поверх всего сайта

## Секции сайта
1. **Nav** — логотип NEURA (serif), ссылки, переключатель языка EN/RU, тема (луна/солнце), CTA "Order" (лаймовая кнопка), бургер на мобилке
2. **Hero** — двухколоночный: слева заголовок + описание + кнопка, справа bento-grid из 4 карточек с blob-визуалами. Заголовок: "We Create / Impossible / Content" — слово "Impossible" скрыто, появляется при наведении (height:0 → 1.15em, fade in снизу)
3. **Ticker** — бегущая строка услуг с лаймовыми точками-разделителями
4. **About** — большой serif-текст описания, 2 колонки текста, ряд статистики (500+ проектов, 12K+ контента, 98% довольных, 48ч доставка) с анимацией счётчиков
5. **Services** — табличный список 01-06 с hover-эффектом (сдвиг, подсветка стрелки). Услуги: Images, Video, Text, Audio, 3D, Code
6. **How it works** — 3 карточки с рамкой и hover-подъёмом: Brief → Generate → Receive
7. **Works** — masonry grid 3 колонки (2 высокие карточки span 2 строки), blob-визуалы + подписи
8. **CTA/Order** — слева заголовок + аватарки "500+ заказов", справа форма (имя, email/telegram, тип генерации select, описание, кнопка "Send Order")
9. **Footer** — большая надпись NEURA® с gradient-fade, 3 колонки ссылок, копирайт

## Фичи
- **i18n**: полный перевод EN/RU через `data-i18n` атрибуты, словарь в JS объекте `T`, сохранение в localStorage
- **Тёмная/светлая тема**: через `[data-theme="light"]` на `<html>`, сохранение в localStorage
- **Scroll reveal**: IntersectionObserver, класс `.reveal` → `.visible`
- **Счётчики**: анимация от 0 до target с ease-out-quart
- **Форма**: при submit показывает "Sent!" / "Отправлено!" на 2.5 сек, потом сбрасывается
- **Preloader**: заполнение полоски, затем clip-path анимация выхода

## Деплой
```bash
# Скопировать файлы в public и задеплоить
cp index.html styles.css script.js public/
npx wrangler deploy
```

## Важные решения
- Прайсы/pricing убраны — клиент добавит позже сам
- Кастомный курсор убран — используется стандартный системный
- Слово "Невозможный" использует `overflow:visible` чтобы буква "й" не обрезалась
- Кнопки и CTA — лаймовые с тёмным текстом (#0a0a0a) для контраста
- На мобилке hero переключается в одну колонку, карточки под текстом
